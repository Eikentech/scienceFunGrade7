# scienceFunGrade7

Interactive, application-based science lessons for Grade 7 students.

## Heat Quest

Three levels: Heat Detective, Heat Explorer, and Heat Engineer. Includes a temperature lab, heat-transfer explorer, lunchbox design challenge, nine quizzes with hints, and browser-local progress.

Open index.html in a browser to learn offline. No dependencies or build step required.

## GitHub Pages

Publish from the main branch, root directory, in Settings > Pages.
