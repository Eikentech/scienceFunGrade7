# scienceFunGrade7

Application-based, interactive science lessons for Grade 7.

- [Foundation: Heat Quest](https://eikentech.github.io/scienceFunGrade7/) — heat flow, transfer methods, insulation, and nine quizzes.
- [Beyond the Basics: Heat Lab](https://eikentech.github.io/scienceFunGrade7/heat-chapter5.html) — three levels, six labs, eighteen mastery checks, and a downloadable learning report.

## Heat Lab topics

1. Heat and temperature, effects of heating, joules/calories, thermometer calibration and reading, Celsius/Fahrenheit/kelvin conversions, clinical and laboratory instruments.
2. Length/area/volume expansion, holes in heated solids, bimetallic thermostats, bridge joints, and water's unusual expansion (enrichment).
3. Conduction/convection/radiation, sea and land breezes, radiation surface properties, fair experiments, and vacuum-flask design.

Original explanations, questions, and qualitative models. This is a companion based on common Grade 7 Heat topics, not a reproduction or edition-verified adaptation of V. K. Sally's book. Scope and reference links appear in the lesson's teacher notes. Thermostat, water-volume, breeze, and flask models are simplified and labelled accordingly.

No dependencies or build step. Open either HTML file in a browser; keep chapter5.css and chapter5.js beside heat-chapter5.html. Progress is stored locally when browser storage is available. No student account or server collection of answers.

GitHub Pages publishes the main branch from the root directory.
